# My Developer Profile Card 🚀

A personal developer profile card built using HTML, CSS, and JavaScript during a GDG Web Development Workshop .

## 🌐 Live Demo

[https://vansh-first-web-developer-project.netlify.app](https://vansh-first-web-developer-project.netlify.app)

## ✨ Features

- Personal profile with profile picture
- About Me section
- Currently Learning section
- Dark Mode / Light Mode toggle
- Social media profile links
- Responsive card layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
